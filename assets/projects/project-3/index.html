Project 3 · Retail Reporting

Retail Sales Analysis & Excel KPI Dashboard

An Excel BI dashboard built on 2023–2025 retail transactions to track revenue, profitability, and channel/category performance with slicer-driven interactivity.

ExcelPower QueryPivotTablesKPI Design

Business Problem & Objectives

  • Provide a compact executive dashboard for multi-year retail performance review.
  • Track trend, channel, region, and category patterns in one workbook.
  • Support fast slicer-driven exploration for operational decision support.

Dataset Profile

  • Raw file: retail_sales_2023_2025.csv with 17,393 rows and 19 columns.
  • Date range: 2023-01-01 to 2025-12-31.
  • 500 customers, 25 products, 5 categories, 5 regions, 2 channels.
  • Total revenue in current file: $2,255,718.05; gross margin: 56.75%.

Methodology

  • Import and clean data using Power Query and structured Excel table design.
  • Build KPI formulas for revenue, margin %, transaction count, and average order value.
  • Create PivotTables/PivotCharts for month trend, channel, region, and category breakdowns.
  • Connect slicers (Year, Channel, Region, Category) to synchronize all visuals.

Findings & Outcomes

  • Dashboard documentation highlights category concentration and clear seasonal demand patterns.
  • Output enables direct comparison of online vs in-store performance by period and region.
  • Workbook structure (Dashboard, PivotData, KPI_Calc) supports repeatable refreshes.
