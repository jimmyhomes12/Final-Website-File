Project 2 · E-commerce Segmentation

E-commerce Sales Performance & RFM Customer Segmentation

This project builds a Python + SQLite pipeline that generates RFM scoring outputs and Tableau-ready files for segmentation and promo performance analysis.

PythonSQLiteSQL CTEsTableauRFM

Business Problem & Objectives

  • Identify high-value and low-engagement customer segments with a reproducible RFM process.
  • Quantify promo-code order behavior from the same synthetic sales dataset.
  • Export clean files for dashboarding and relationship-based Tableau modeling.

Dataset & Data Products

  • Raw dataset: synthetic_ecommerce_sales_2025.csv (5,000 rows, 8 columns, 2025-01-01 to 2025-12-31).
  • Unique customers in provided data: 797.
  • Primary outputs: output/promo_roi.csv, output/rfm_segments.csv, data/rfm_scores.csv, data/full_ecom.csv.

Methodology

  • Load CSV into SQLite table ecom using Python and SQLAlchemy.
  • Create views for order-level and customer-level analysis.
  • Build RFM scores with SQL CTEs and NTILE(5) scoring logic.
  • Export segment and promo summaries, then map to Tableau fields.

Key Findings (Current Outputs)

  • Promo summary includes four active codes (SAVE10, SUMMER20, FLASH30, WELCOME15).
  • Highest 5-5-5 segment count in current output is 59 customers.
  • Promo and non-promo average order values are close in this snapshot ($255.46 vs $254.32).
  • RFM outputs are ready for heatmap views and segment drilldowns in Tableau.
